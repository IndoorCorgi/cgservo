## 概要
Raspberry Pi用 サーボモータードライバー基板「RPZ-RC-Servo」および、
Raspberry Pi用 ブラシレスモーター制御基板「RPZ-RC-Motor」を制御するソフトウェアです。
Pythonパッケージを使うことでご自身のプログラムからRCサーボモーターやRCブラシレスモーターESCを制御することができます。
